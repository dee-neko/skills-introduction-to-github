# テンプレート編集ガイド

このガイドでは、講義依頼文書のテンプレートを編集する方法について説明します。

## 基本構文

テンプレートは Handlebars 構文を使用しています。

### 変数の展開

`{{変数名}}` の形式で変数を展開できます。

```handlebars
{{講師名}} 様

お世話になっております。
{{担当者名}}と申します。
```

### 条件分岐

`{{#if 変数}}...{{/if}}` で条件分岐ができます。

```handlebars
{{#if 備考}}
【備考】
{{備考}}
{{/if}}
```

変数が存在する場合のみ、その内容を表示します。

### その他の構文

- `{{#unless 変数}}...{{/unless}}`: 変数が存在しない場合
- `{{#each 配列}}...{{/each}}`: 配列のループ処理
- `{{else}}`: if文のelse節

## 使用可能な変数

CSVファイルのカラム名をそのまま変数として使用できます。

### 必須変数

- `{{課目名}}` - 講義の課目名
- `{{講師名}}` - 講師の名前
- `{{所属}}` - 講師の所属
- `{{講義日時}}` - 講義の日時
- `{{講義場所}}` - 講義の場所
- `{{担当者名}}` - 依頼担当者の名前
- `{{担当者メール}}` - 依頼担当者のメールアドレス

### オプション変数

- `{{備考}}` - その他の備考事項

## サンプルテンプレート

### 基本テンプレート

```handlebars
{{講師名}} 様

お世話になっております。
{{担当者名}}と申します。

このたび、{{課目名}}の講義をお願いしたく、ご連絡を差し上げました。

【講義詳細】
・課目名: {{課目名}}
・日時: {{講義日時}}
・場所: {{講義場所}}
・所属: {{所属}}

{{#if 備考}}
【備考】
{{備考}}
{{/if}}

ご多忙のところ恐縮ですが、ご検討のほどよろしくお願い申し上げます。

{{担当者名}}
{{担当者メール}}
```

### フォーマル版テンプレート

```handlebars
{{講師名}} 様

平素より大変お世話になっております。
{{担当者名}}と申します。

この度は、{{課目名}}の講義につきまして、
{{講師名}}様にご講義をお願いしたく、ご連絡を差し上げました。

■ 講義詳細
┌─────────────────────
│ 課目名: {{課目名}}
│ 日 時: {{講義日時}}
│ 場 所: {{講義場所}}
│ ご所属: {{所属}}
└─────────────────────

{{#if 備考}}
■ 備考事項
{{備考}}
{{/if}}

ご多用中誠に恐縮ではございますが、
何卒ご検討のほどよろしくお願い申し上げます。

――――――――――――――――――
{{担当者名}}
{{担当者メール}}
――――――――――――――――――
```

### カジュアル版テンプレート

```handlebars
{{講師名}}様

こんにちは、{{担当者名}}です。

{{課目名}}の講義について、{{講師名}}様にぜひお願いしたいと思い、
ご連絡させていただきました。

【講義情報】
課目: {{課目名}}
日時: {{講義日時}}
場所: {{講義場所}}

{{#if 備考}}
※ {{備考}}
{{/if}}

ご検討いただければ幸いです。
よろしくお願いいたします。

{{担当者名}}
{{担当者メール}}
```

## 注意事項

1. **変数名は正確に**: CSVファイルのカラム名と完全に一致させてください
2. **改行と空白**: テンプレート内の改行や空白はそのまま出力されます
3. **特殊文字**: `{{` と `}}` はHandlebars構文として解釈されるため、文字として使用する場合はエスケープが必要です

## トラブルシューティング

### エラー: "変数が見つかりません"

- CSVファイルのカラム名とテンプレート内の変数名が一致しているか確認してください

### 条件分岐が動作しない

- `{{#if 備考}}` のように、変数名が正確か確認してください
- 終了タグ `{{/if}}` を忘れていないか確認してください

### 生成された文書が空白

- テンプレートに最低限の変数（講師名、課目名など）が含まれているか確認してください
