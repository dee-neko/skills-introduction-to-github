# 講義依頼文書生成ツール - ローカル実行ガイド

## 🎯 このツールについて

CSVファイルから講義依頼文書を自動生成し、メールクライアントで使用できる下書きファイル（.eml形式）またはプレーンテキスト（.txt形式）として出力するWebアプリケーションです。

**特徴:**
- ✅ **HTTPサーバー不要** - ブラウザで直接HTMLファイルを開いて実行可能
- ✅ **完全オフライン動作** - インターネット接続不要（初回読み込み後）
- ✅ **データ保護** - すべての処理がブラウザ内で完結、データがサーバーに送信されることはありません

## 📦 ダウンロード＆実行方法

### 方法1: GitHubからクローン（推奨）

```bash
# リポジトリをクローン
git clone https://github.com/dee-neko/skills-introduction-to-github.git

# ディレクトリに移動
cd skills-introduction-to-github

# ブランチを切り替え（最新版）
git checkout claude/lecture-request-generator-tImo4
```

### 方法2: ZIPファイルでダウンロード

1. GitHubページの「Code」→「Download ZIP」をクリック
2. ダウンロードしたZIPファイルを解凍
3. 解凍したフォルダを開く

## 🚀 実行手順

### ステップ1: index.html を開く

以下のいずれかの方法で `index.html` を開きます：

- **方法A**: ファイルマネージャーで `index.html` をダブルクリック
- **方法B**: ブラウザに `index.html` をドラッグ&ドロップ
- **方法C**: ブラウザのアドレスバーに以下を入力（パスは適宜変更）
  ```
  file:///C:/path/to/skills-introduction-to-github/index.html
  ```

### ステップ2: サンプルCSVで動作確認

1. アプリケーションが開いたら、「サンプルCSVをダウンロード」リンクをクリック
2. ダウンロードした `sample-data.csv` を「ファイルを選択」ボタンでアップロード
3. データプレビューが表示されることを確認

### ステップ3: 文書生成

1. 「次へ」ボタンをクリックしてテンプレート編集画面へ
2. デフォルトテンプレートを確認（必要に応じて編集）
3. 「文書を生成」ボタンをクリック

### ステップ4: エクスポート

1. 生成された文書をプレビュー
2. 出力形式を選択（.eml または .txt）
3. 「すべてダウンロード」または個別の「ダウンロード」ボタンをクリック

## 📄 CSVファイルの形式

### 必須カラム

CSVファイルには以下のカラムが必須です：

| カラム名 | 説明 | 例 |
|---------|------|-----|
| 課目名 | 講義の課目名 | データサイエンス入門 |
| 講師名 | 講師の名前 | 山田太郎 |
| 所属 | 講師の所属 | ○○大学情報学部 |
| 講義日時 | 講義の日時 | 2026年4月15日(火) 13:00-14:30 |
| 講義場所 | 講義の場所 | 第1講義室 |
| 担当者名 | 依頼者の名前 | 鈴木花子 |
| 担当者メール | 依頼者のメールアドレス | suzuki@example.com |
| 備考 | （オプション）追加情報 | プロジェクター使用 |

### サンプルCSV

```csv
課目名,講師名,所属,講義日時,講義場所,担当者名,担当者メール,備考
データサイエンス入門,山田太郎,○○大学情報学部,2026年4月15日(火) 13:00-14:30,第1講義室,鈴木花子,suzuki@example.com,プロジェクター使用
機械学習基礎,佐藤次郎,△△研究所,2026年4月22日(火) 13:00-14:30,第1講義室,鈴木花子,suzuki@example.com,
Webアプリケーション開発,田中美咲,株式会社××,2026年5月13日(火) 13:00-14:30,第1講義室,鈴木花子,suzuki@example.com,WiFi環境必須
```

## ✉️ エクスポート形式

### .eml形式（メールクライアント用）

- Outlook、Thunderbird、Apple Mailなどのメールクライアントで開けます
- 件名、宛先、本文が自動的に設定されます
- メールクライアントで開いて、そのまま送信または編集できます

### .txt形式（テキストファイル）

- どのテキストエディタでも開けます
- シンプルなテキスト形式で保存されます
- コピー&ペーストして他のアプリケーションで使用できます

## 🎨 テンプレートのカスタマイズ

Step 3のテンプレート編集画面で、文書のフォーマットをカスタマイズできます。

### 使用可能な変数

- `{{課目名}}`
- `{{講師名}}`
- `{{所属}}`
- `{{講義日時}}`
- `{{講義場所}}`
- `{{担当者名}}`
- `{{担当者メール}}`
- `{{備考}}`

### 条件分岐

備考がある場合のみ表示したい場合：

```handlebars
{{#if 備考}}
【備考】
{{備考}}
{{/if}}
```

## ⚠️ トラブルシューティング

### ファイルがアップロードできない

- ファイルサイズが5MB以下か確認してください
- ファイルの拡張子が `.csv` であることを確認してください
- 文字エンコーディングが UTF-8 であることを確認してください

### 文書が正しく生成されない

- CSVファイルに必須カラムがすべて含まれているか確認してください
- テンプレート編集画面でエラーメッセージが表示されていないか確認してください
- ブラウザのコンソールを開いてエラーメッセージを確認してください（F12キー）

### ブラウザのコンソールの開き方

- **Windows/Linux**: `F12` キーまたは `Ctrl + Shift + I`
- **Mac**: `Cmd + Option + I`

## 🔒 セキュリティとプライバシー

- すべての処理がブラウザ内で完結します
- データがサーバーに送信されることはありません
- 外部ライブラリ（PapaParse、Handlebars、FileSaver）はCDN経由で読み込まれますが、データの送信は行いません
