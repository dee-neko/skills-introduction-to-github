# 講義依頼文書生成ツール - ローカル実行ガイド

## 🎯 このツールについて

CSVファイルから講義依頼文書を自動生成し、メールクライアントで使用できる下書きファイル（.eml形式）またはプレーンテキスト（.txt形式）として出力するWebアプリケーションです。

**特徴:**
- ✅ **HTTPサーバー不要** - ブラウザで直接HTMLファイルを開いて実行可能
- ✅ **完全オフライン動作** - インターネット接続不要（初回読み込み後）
- ✅ **データ保護** - すべての処理がブラウザ内で完結、データがサーバーに送信されることはありません

## 📦 ダウンロード＆実行方法

### 🏢 組織のプロキシ環境で使用する場合

**git cloneができない環境（プロキシ制限がある場合）でも、このツールは問題なく動作します。**

#### 方法1: ZIPファイルで配布（最も簡単・推奨）

1. **ブラウザでGitHubにアクセスできる場合**:
   - https://github.com/dee-neko/skills-introduction-to-github を開く
   - 「Code」→「Download ZIP」をクリック
   - ダウンロードしたZIPファイルを解凍

2. **GitHubにアクセスできない場合**:
   - このツールのZIPファイルをメールやファイル共有サービス経由で入手
   - 解凍後、`index.html`をブラウザで開くだけで使用可能

3. **必要最小限のファイル構成**:
   ```
   skills-introduction-to-github/
   ├── index.html              # ←ダブルクリックで開く
   ├── css/                     # スタイルシート
   ├── js/app-standalone.js     # アプリケーション本体
   └── examples/sample-data.csv # サンプルデータ
   ```

#### 方法2: プロキシ設定後にgit clone

**IT部門に以下の情報を確認してください**:
- プロキシサーバーのアドレスとポート
- 認証が必要な場合: ユーザー名とパスワード
- GitHubへのアクセス許可

```bash
# プロキシ設定（認証なし）
git config --global http.proxy http://プロキシサーバー:ポート
git config --global https.proxy http://プロキシサーバー:ポート

# プロキシ設定（認証あり）
git config --global http.proxy http://ユーザー名:パスワード@プロキシサーバー:ポート
git config --global https.proxy http://ユーザー名:パスワード@プロキシサーバー:ポート

# リポジトリをクローン
git clone https://github.com/dee-neko/skills-introduction-to-github.git
cd skills-introduction-to-github
git checkout claude/lecture-request-generator-tImo4
```

### 💻 通常の環境（プロキシ制限なし）

3. 解凍したフォルダを開く

## 🚀 実行手順

### ステップ1: index.html を開く

以下のいずれかの方法で `index.html` を開きます：

#### 方法A: ファイルエクスプローラーから開く（最も簡単）
1. 解凍したフォルダを開く
2. `index.html` をダブルクリック
3. デフォルトのブラウザで自動的に開きます

#### 方法B: PowerShellから開く（Windows）

```powershell
# フォルダに移動
cd C:\Users\admin\skills-introduction-to-github

# ブラウザで開く
Start-Process .\index.html
```

#### 方法C: ブラウザにドラッグ&ドロップ
- ブラウザウィンドウに `index.html` をドラッグ&ドロップ

#### 方法D: ブラウザのアドレスバーに直接入力
```
file:///C:/Users/admin/skills-introduction-to-github/index.html
```
（パスは実際の場所に合わせて変更してください）

### ステップ2: サンプルCSVで動作確認

1. アプリケーションが開いたら、「サンプルCSVをダウンロード」リンクをクリック
2. ダウンロードした `sample-data.csv` を「ファイルを選択」ボタンでアップロード
3. データプレビューが表示されることを確認

### ステップ3: 文書生成

1. 「次へ」ボタンをクリックしてテンプレート編集画面へ
2. デフォルトテンプレートを確認（必要に応じて編集）
3. 「文書を生成」ボタンをクリック

### ステップ4: エクスポート

1. 生成された文書をプレビュー
2. 出力形式を選択（.eml または .txt）
3. 「すべてダウンロード」または個別の「ダウンロード」ボタンをクリック

## 📄 CSVファイルの形式

| カラム名 | 説明 | 例 |
|---------|------|-----|
| 課目名 | 講義の課目名 | データサイエンス入門 |
| 講師名 | 講師の名前 | 山田太郎 |
| 所属 | 講師の所属 | ○○大学情報学部 |
| 講義日時 | 講義の日時 | 2026年4月15日(火) 13:00-14:30 |
| 講義場所 | 講義の場所 | 第1講義室 |
| 担当者名 | 依頼者の名前 | 鈴木花子 |
| 担当者メール | 依頼者のメールアドレス | suzuki@example.com |

## ✉️ エクスポート形式

### .eml形式（メールクライアント用）

- Outlook、Thunderbird、Apple Mailなどのメールクライアントで開けます
- 件名、宛先、本文が自動的に設定されます
- メールクライアントで開いて、そのまま送信または編集できます

### .txt形式（テキストファイル）

- どのテキストエディタでも開けます
- シンプルなテキスト形式で保存されます
- コピー&ペーストして他のアプリケーションで使用できます

## ⚠️ トラブルシューティング

### 🌐 インターネット接続について（重要）

このツールは**ほぼオフライン**で動作しますが、以下の外部ライブラリをCDN経由で読み込みます：

- PapaParse（CSV解析）
- Handlebars（テンプレートエンジン）
- FileSaver（ファイルダウンロード）

**初回起動時のみインターネット接続が必要です。** その後、ブラウザがライブラリをキャッシュするため、オフラインでも動作します。

#### プロキシ環境でCDNにアクセスできない場合

もしブラウザでCDNライブラリが読み込めない場合（プロキシでブロックされている場合）：

1. **ブラウザのコンソール（F12）でエラーを確認**
2. **IT部門に以下のCDN URLへのアクセス許可を依頼**:
   - `https://cdn.jsdelivr.net`

または、完全オフライン版が必要な場合はIT部門にご相談ください。

### ファイルがアップロードできない

- ファイルサイズが5MB以下か確認してください
- ファイルの拡張子が `.csv` であることを確認してください
- 文字エンコーディングが UTF-8 であることを確認してください

### 文書が正しく生成されない

- CSVファイルに必須カラムがすべて含まれているか確認してください
- テンプレート編集画面でエラーメッセージが表示されていないか確認してください
- ブラウザのコンソールを開いてエラーメッセージを確認してください（F12キー）

### アプリケーションが起動しない・真っ白な画面が表示される

**原因**: 外部ライブラリ（CDN）の読み込みに失敗している可能性があります。

**対処法**:
1. ブラウザのコンソール（F12）を開く
2. 赤いエラーメッセージを確認
3. `cdn.jsdelivr.net` へのアクセスがブロックされている場合:
   - IT部門にCDNへのアクセス許可を依頼
   - または、インターネット接続がある環境で一度起動してキャッシュさせる

### ブラウザのコンソールの開き方

- **Windows/Linux**: `F12` キーまたは `Ctrl + Shift + I`
- **Mac**: `Cmd + Option + I`

## 🔒 セキュリティとプライバシー

### データ保護
- ✅ **完全クライアントサイド処理**: すべての処理がブラウザ内で完結
- ✅ **データ送信なし**: CSVデータや生成された文書がサーバーに送信されることは一切ありません
- ✅ **プロキシ環境でも安全**: file://プロトコルで動作するため、組織のネットワークを経由しません

### 外部依存
- 外部ライブラリ（PapaParse、Handlebars、FileSaver）はCDN経由で**読み込みのみ**
- これらのライブラリはデータの送信を行いません
- ブラウザキャッシュ後は完全オフラインで動作可能

### 機密情報の取り扱い
このツールは以下の用途に適しています：
- ✅ 組織内の講義依頼文書生成
- ✅ 個人情報を含むCSVデータの処理（ブラウザ内で完結）

## ❓ よくある質問（FAQ）

### Q1: HTTPサーバーを起動する必要はありますか？
**A**: いいえ、不要です。`index.html`をダブルクリックするだけで動作します。

### Q2: プロキシでgit cloneができません。どうすればいいですか？
**A**: ZIPファイルでダウンロードする方法をお試しください。ブラウザでGitHubにアクセスできる場合は、「Code」→「Download ZIP」からダウンロードできます。GitHubにもアクセスできない場合は、メールやファイル共有で入手してください。

### Q3: オフラインで使用できますか？
**A**: はい、ほぼオフラインで使用可能です。ただし、初回起動時のみインターネット接続が必要です（CDNライブラリの読み込みのため）。その後はオフラインで動作します。

### Q4: CSVファイルのデータは外部に送信されますか？
**A**: いいえ、一切送信されません。すべての処理はブラウザ内で完結します。

### Q5: .emlファイルをメールクライアントで開けません
**A**: 以下を確認してください：
- メールクライアント（Outlook、Thunderbirdなど）がインストールされているか
- .emlファイルの関連付けが正しく設定されているか
- Windowsの場合、右クリック→「プログラムから開く」→メールクライアントを選択

### Q6: プロキシ環境でCDNライブラリが読み込めません
**A**: IT部門に `https://cdn.jsdelivr.net` へのアクセス許可を依頼してください。または、インターネット接続がある環境で一度起動して、ブラウザにキャッシュさせる方法もあります。

### Q7: Windows以外（Mac、Linux）でも使えますか？
**A**: はい、使用可能です。どのOSでも、ブラウザで `index.html` を開くだけで動作します。

### Q8: 複数の人で使用できますか？
**A**: はい。ZIPファイルを配布すれば、各自のPCで独立して使用できます。データがサーバーに保存されることはありません。
