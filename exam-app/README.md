# 🔬 放射線取扱主任者試験 学習アプリ

第１種放射線取扱主任者試験の学習用HTMLアプリケーションです。

## ✨ 特徴

- **📱 レスポンシブデザイン** - PC・スマホどちらでも快適に学習
- **⚡ 2つの採点モード**
  - 一括採点モード: 全問解答後にまとめて採点
  - 即時判定モード: 回答するとすぐに正誤判定
- **📐 LaTeX数式対応** - MathJaxによる美しい数式表示
- **📊 詳細な解説** - 正解・不正解を問わず、すべての問題に詳細解説
- **📁 JSON読み込み機能** - 問題作成者が独自の問題セットを読み込み可能
- **💾 回答の保存・読み込み** - 途中で中断しても続きから再開可能
- **📤 回答のエクスポート/インポート** - 回答データを別PCで共有可能
- **📄 採点結果のHTML保存** - 結果を保存して印刷・PDF化が可能
- **🌐 オフライン利用可能** - インターネット不要（数式表示のみオンライン必要）

## 📁 ファイル構成

```
exam-app/
├── index.html          # メインアプリケーション
├── styles.css          # スタイルシート
├── app.js              # アプリケーションロジック
├── questions.json      # 問題データ
├── images/             # 問題画像格納フォルダ
└── README.md           # このファイル
```

## 🚀 使い方

### 1. アプリを開く

`index.html` をWebブラウザで開いてください。

```bash
# ブラウザで直接開く、または
open exam-app/index.html
```

### 2. 採点モードを選択

- **📝 一括採点モード（デフォルト）**
  - 全問解答後に「採点する」ボタンをクリック
  - まとめて採点・解説表示

- **⚡ 即時判定モード**
  - 回答を選択するとすぐに正誤判定
  - リアルタイムで学習効果を確認

### 3. 問題を解く

- 好きな順番で問題を解けます
- 進捗バーで解答状況を確認

### 4. 結果を確認

- 採点後、各問題に詳細な解説が表示されます
- 正解・不正解の選択肢すべてに解説あり

### 5. リセット

「リセット」ボタンで最初からやり直せます。

## 🆕 新機能の使い方

### 📁 問題作成者用機能

**JSONファイルから問題を読み込む**

1. 「📁 問題作成者用機能」セクションを開く
2. 「📁 JSONファイルを読み込む」ボタンをクリック
3. 作成した`questions.json`ファイルを選択
4. 問題が読み込まれ、アプリに反映されます

**使用例：**
- 物理試験用、化学試験用など、複数の問題セットを切り替え
- 新しい問題を追加して動作確認
- 読み込んだ状態でアプリ全体を配布

### 💾 回答の保存・読み込み

**ブラウザに回答を保存（localStorage）**

1. 「💾 回答の保存・読み込み」セクションを開く
2. 「💾 回答を保存」ボタンをクリック
3. ブラウザのローカルストレージに回答が保存されます
4. 次回「📂 回答を読み込み」で続きから再開できます

**注意：** ブラウザのキャッシュをクリアすると保存データも削除されます

### 📤 回答のエクスポート・インポート

**回答データをファイルとして保存**

1. 「📤 回答をエクスポート」ボタンをクリック
2. `exam-answers-YYYY-MM-DD.json`ファイルがダウンロードされます
3. このファイルを別のPCやバックアップとして保管できます

**別のPCやブラウザで回答を復元**

1. 「📥 回答をインポート」ボタンをクリック
2. 保存した`exam-answers-YYYY-MM-DD.json`を選択
3. 回答が復元されます

**使用例：**
- PCで途中まで解いた問題をスマホで続きから解く
- 複数人で回答を共有して議論
- バックアップとして保存

### 📄 採点結果の保存

**採点後にHTML形式で結果を保存**

1. 採点を実行（「採点する」ボタン）
2. 採点結果画面で「💾 採点結果を保存（HTML）」をクリック
3. `exam-result-YYYY-MM-DD.html`ファイルがダウンロードされます

**保存されたHTMLファイルには以下が含まれます：**
- スコアと正答率
- 全問題と選択した回答
- 正解・不正解の表示
- 詳細な解説

**活用方法：**
- ブラウザで開いて印刷（Ctrl+P / Cmd+P）
- PDFとして保存（印刷→PDFに保存）
- 学習記録として保管
- 復習時に参照

## 📝 問題データの編集方法

### questions.json の構造

```json
[
  {
    "id": 1,
    "question": "問題文（LaTeX数式も使用可: $E=mc^2$）",
    "hasImage": false,
    "choices": [
      "選択肢1",
      "選択肢2",
      "選択肢3",
      "選択肢4",
      "選択肢5"
    ],
    "correctAnswer": 0,
    "explanation": "簡単な解説",
    "detailedExplanation": {
      "calculation": "計算過程の詳細",
      "choiceExplanations": [
        "選択肢1の解説",
        "選択肢2の解説",
        "選択肢3の解説",
        "選択肢4の解説",
        "選択肢5の解説"
      ]
    }
  }
]
```

### フィールド説明

| フィールド | 必須 | 説明 |
|-----------|------|------|
| `id` | ✅ | 問題番号（ユニーク） |
| `question` | ✅ | 問題文（LaTeX使用可） |
| `hasImage` | ✅ | 画像を使用するか（true/false） |
| `imagePath` | ⚠️ | 画像のパス（hasImage=trueの場合） |
| `imageAlt` | - | 画像の代替テキスト |
| `choices` | ✅ | 選択肢の配列（LaTeX使用可） |
| `correctAnswer` | ✅ | 正解の選択肢インデックス（0始まり） |
| `explanation` | ✅ | 簡潔な解説 |
| `detailedExplanation` | - | 詳細な解説オブジェクト |

### LaTeX数式の書き方

- **インライン数式**: `$E=mc^2$`
- **ディスプレイ数式**: `$$E=mc^2$$`

例：
```json
"question": "運動エネルギー $E = \\frac{1}{2}mv^2$ から速度を求めよ。"
```

### 画像の追加方法

1. 画像を `images/` フォルダに配置
2. `questions.json` で設定：

```json
{
  "hasImage": true,
  "imagePath": "images/question1.png",
  "imageAlt": "問1の数式画像"
}
```

## 🛠️ トラブルシューティング

### 数式が表示されない

- インターネット接続を確認（MathJax CDN使用）
- オフライン対応が必要な場合は、MathJaxをローカルに配置

### 画像が表示されない

- `images/` フォルダに画像があるか確認
- `questions.json` の `imagePath` が正しいか確認

### 問題が表示されない

- ブラウザのコンソールでエラーを確認
- `questions.json` のJSON形式が正しいか確認
  - JSONバリデーター: https://jsonlint.com/

## 🎓 JSON編集のコツ

### JSONエディタの使用

- **VSCode**: JSON編集に最適（インテリセンス、バリデーション）
- **オンラインエディタ**: https://jsoneditoronline.org/

### よくあるミスと対策

```json
// ❌ 最後のカンマ
{
  "id": 1,
  "question": "問題文",  // ← この最後のカンマは削除
}

// ✅ 正しい
{
  "id": 1,
  "question": "問題文"
}
```

```json
// ❌ LaTeXのバックスラッシュ
"question": "$\frac{1}{2}$"  // ← エラー

// ✅ 正しい（バックスラッシュをエスケープ）
"question": "$\\frac{1}{2}$"
```
