# 📷 問題画像フォルダ

このフォルダには、問題で使用する画像ファイルを配置します。

## 画像の追加方法

1. **画像ファイルを配置**
   - このフォルダ (`exam-app/images/`) に画像ファイルをコピー
   - 推奨形式: PNG, JPG, SVG

2. **questions.json で参照**
   ```json
   {
     "id": 1,
     "question": "問題文...",
     "hasImage": true,
     "imagePath": "images/question1.png",
     "imageAlt": "問1の数式画像"
   }
   ```

## 画像ファイル命名規則（推奨）

- `question1.png` - 問1の画像
- `question2.png` - 問2の画像
- `question10_diagram.png` - 問10の図解

## 現在のサンプル問題

プロトタイプでは、問1が画像を使用する設定になっていますが、実際の画像ファイルは含まれていません。

問1の画像（提供された画像）を `question1.png` として保存してください。

## 注意事項

- 画像が見つからない場合、アプリは代替テキストを表示します
- 大きすぎる画像は自動的にリサイズされます（レスポンシブ対応）
- スマホでも見やすいように、十分な解像度の画像を使用してください
